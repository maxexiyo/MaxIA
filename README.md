MaxIA

Hola esto es un bot que hice de discord solamente por que se me ocurrio y estaba aburrido

> ⚠️ Es un bot privado: no está pensado para invitarse públicamente.

---

## ✨ Características

- **Módulo IA**: responde de forma contextual, con memorias automáticas de usuarios, apodos, búsqueda por canales e historial inteligente. cuenta con un sistema de rotacion de api keys para en caso de que fallen por limite de cuota o algo.
- **Personalidades**: cambia de modo con `!max personaje <max|neko>`.
- **Moderación**: warns con auto-ban, suspensiones con tiempo, bans y modlog configurable (esto aun en fase beta no a sido probado).
- **Bienvenidas y despedidas** con variables y mensajes personalizables.
- **Reaction roles** (tipo Carl-bot) y roles de color con hex.
- **Música** con Lavalink/Wavelink y búsqueda en YouTube Music.
- **TTS en canal de voz** (Gemini TTS con edge-tts de respaldo).
- **Transcripción de audios** con reacción 📝.
- **Radio Maxia** (`!max radio`): estación 24/7 dirigida por IA, con programas, noticiero con datos sobre latinoamerica, hora y peticiones(aun no se prueban las peticiones.
- **Panel de configuración** con botones y modales.
- **Base de datos separada por servidor**, sin cruces de datos, esto para guardar configuraciones

todo ta pensado para uso gratuito buscando formas y maneras de hacer que las funcionalidades con IA funcionen gratuito y con recursos de hardware limitados
literalmente limitados, el servidor del bot corre en un telefono al que se le fue intalado termux con el distro proot de ubuntu
